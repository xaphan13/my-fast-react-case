Вы знаете Python и базовый JS/TS. Хотите собрать современное веб-приложение
«бэкенд + SPA» и понять, **почему** оно устроено именно так, а не иначе. Не
ищете готовый шаблон для копипасты — ищете **карту архитектуры**.

## Главные идеи цикла

- **React — в браузере, FastAPI — на сервере.** Node нужен только как
  инструмент **сборки** фронтенда; в проде работает один Python-процесс.
- **Контракт JSON API — единственная связь.** Бэкенд не знает про фронт,
  фронт не знает про бэкенд. Pydantic-схемы = типизированный контракт,
  Swagger `/docs` = автодокументация.
- **DI (`Depends`) — главный паттерн FastAPI.** Один алиас
  `CurrentSession` заменяет сотни строк ручного управления сессиями.
- **Cookie-сессии + CSRF**, а не JWT в localStorage. Для классического
  сайта с формами это проще и безопаснее.
- **Типы на обоих концах** (pydantic ↔ TypeScript) убирают целый класс
  багов «а что приходит в этом JSON?».

## Состояние кода, под которое написаны гайды

- Ветка: `auth_refactor` (на 2026-09-06).
- `len(main_app.routes) == 42` — baseline, проверено запуском.
- Слой авторизации блога разнесён на **три файла**:
  `md_articles/middleware_auth.py` (HTTP-middleware + 422-handler),
  `md_articles/helpers_auth.py` (bcrypt, CSF, `user_out`, сессионные
  хелперы), `md_articles/api_auth.py` (JSON-эндпоинты auth).
- JSON API блога — **два роутера** под одним префиксом `/api/blog`:
  `router_auth_api` (`/csrf`, `/current_user`, `/register`, `/login`,
  `/logout`, `/account`) и `router_blog_api` (`/sections`, `/articles`,
  `/articles/{art_id}`, `/art_manage`, `/art_manage/add_all`,
  `/art_manage/meta`, `/art_manage/sync`).
- SPA catch-all и mount собранного фронта — в `md_articles/setup_frontend.py`
  (`spa_fallback`, `mount_vite_react_assets`, `include_router_api_frontend`).
- Vite проксирует `/api` и `/static` на `:8000` — никакого CORS не нужно.

Если вы читаете гайд, а в репозитории что-то поменялось — свериться
можно запуском `cd fastapi-application && ../.venv/bin/python -c "from main import main_app; print(len(main_app.routes))"`
(должно быть 42) и `git log -n 5 -- Guide_dev/`.
